# Mini Battle Arena — iPhone Safari Edition

A mobile-first browser remake inspired by the supplied Godot Mini Battle Arena project.

## Play locally
Open `index.html` from a static web server. The game loads Three.js from jsDelivr, so an internet connection is required.

## Deploy free with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment, then open:
   https://naiksadashiv352-sudo.github.io/mini-battle-arena/

## Included
- Procedural 3D neon arena and four selectable heroes
- Solo, Survival and Practice modes
- Basic enemy bot movement and melee attacks
- Three weapon types, health, eliminations, rewards and saved coins/level
- Touch joystick, fire, jump and weapon switch controls

## Notes
This is a browser remake of the game concepts, not a direct conversion of Godot scenes or imported 3D assets. Multiplayer, missions, detailed weapon projectiles, and production-grade balancing are not implemented yet. Test on iPhone Safari and desktop before public launch.
